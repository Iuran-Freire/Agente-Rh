          RODAR AGORA

          Para o botão ⚡ Rodar agora disparar o agente direto daqui, cole uma chave do GitHub com permissão só para rodar workflows deste repositório.

          1. Crie em github.com/settings/personal-access-tokens/new
          2. Repository access: Only select repositories → Agente-Rh
          3. Permissions → Actions: Read and write (nenhuma outra)

          A chave fica salva só neste navegador (localStorage). Ela nunca vai para o repositório nem para outras pessoas. Sem chave, o botão abre a página do GitHub.
